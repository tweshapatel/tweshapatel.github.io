# Twesha Patel — Portfolio

Static site for GitHub Pages.

- `index.html` — portfolio (Home, What I Do, Career, Off Duty, Contact)
- `neil/index.html` — personal page for Neil (not indexed by search engines)
- `assets/img/` — photos and logos. Add your headshot as `assets/img/headshot.jpg` (4:5 portrait) and it appears on Home automatically.
- `assets/Twesha-Patel-CV.pdf` — the CV behind the Download CV link. Replace the file (same name) to update it.
- `assets/dc-lite.js` — small script that powers the tabs, flips and pop-ups.
